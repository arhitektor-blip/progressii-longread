# Задание 4. Комплект «Прогрессии вокруг нас» (Алгебра, 9 класс)

Взаимосвязанный комплект цифровых продуктов:
1. **Продукт 1 — образовательный мультимедийный лонгрид** — `index.html` (веб-страница занятия).
2. **Продукт 2 — ментальная карта (вариант А, ≥3 уровней ветвления)** — `mindmap.png / .svg / .pdf`, исходник для правки `mindmap.drawio`.
   Карта уже **встроена картинкой в лонгрид** (раздел 5 «Смысловая визуализация»).

## Состав пакета

| Файл | Что это |
|---|---|
| `index.html` | Лонгрид: обложка + методпаспорт, 4 блока теории, 4 иллюстрации с подписями (3 авторских SVG + карта), 2 встроенных видео (Rutube), 3 контрольных вопроса, проблемный кейс «Вклад под 10%», мини-задача «Шахматная доска», интерактивный тренажёр (8 задач с разбором), рефлексия. |
| `mindmap.png` | Ментальная карта в высоком разрешении (6176×4296). Для сдачи и вставки в конструкторы. |
| `mindmap.svg` | Та же карта в векторе (бесконечное качество при приближении). Открывается в любом браузере. |
| `mindmap.pdf` | Печать-версия карты (одна страница‑плакат). |
| `mindmap.drawio` | Редактируемый исходник карты. Открывается на https://app.diagrams.net → File → Open. |
| `mapgen.mjs` | Генератор карты (по желанию: `node mapgen.mjs` пересоздаёт svg/pdf/drawio). |
| `mindmap_print.html` | Вспомогательный файл для генерации PDF (нужен только mapgen.mjs). |

## Как опубликовать лонгрид (получить публичную ссылку)

Лонгрид — самодостаточный HTML + соседние файлы карты. Загрузите **всю папку целиком** на любой статик-хостинг:

### Вариант 1. Netlify Drop (2 минуты)
1. Зайдите на https://app.netlify.com/drop (нужен бесплатный аккаунт, чтобы ссылка жила постоянно).
2. Перетащите папку `zadanie4-progressii` в окно — получите ссылку вида `https://<имя>.netlify.app`.
3. Проверьте её в режиме «Инкогнито».

### Вариант 2. GitHub Pages
1. Создайте публичный репозиторий (например, `progressii-longread`) и загрузите все файлы папки.
2. Settings → Pages → Source: `main` / `(root)` → Save.
3. Ссылка: `https://<ваш-ник>.github.io/progressii-longread/`. Проверьте в «Инкогнито».

### Вариант 3. Отправка карты отдельно
- Ссылка на просмотр карты — публичная ссылка на `mindmap.png` (например, из поста ВК, Google Диска/Яндекс.Диска с доступом «по ссылке», или раздел карты внутри опубликованного лонгрида).
- Для сдачи приложите сам файл `mindmap.png` (или `mindmap.pdf`) — все надписи читаются при приближении.

## Готовый методический комментарий (для поля сдачи)

> Комплект работает в модели «перевёрнутого класса»: дома до занятия ученик проходит мультимедийный лонгрид с двумя видеоуроками и сразу проверяет себя в интерактивном тренажёре с разбором ошибок, а проблемный кейс и мини-задача разбираются в парах на уроке. Ментальная карта служит опорным конспектом: перед контрольной или ОГЭ тема повторяется по ней за 3–5 минут, а формулы держатся в памяти благодаря цветовым ветвям «АП / ГП». Отдельный сценарий — самостоятельный разбор пропущенной темы: карта показывает структуру, лонгрид заполняет детали, тренажёр даёт диагностику.
